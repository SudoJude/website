# Jude Myers Design

My portfolio site, built with [Astro](https://astro.build) and hosted on [Cloudflare](https://www.cloudflare.com) at [judemyers.eu](https://judemyers.eu).

It's a static site covering my design projects, a blog, photography, and an about page. Projects and blog posts are written in Markdown, and the photography gallery is driven by a single YAML file. Pushing to `main` builds and deploys the site automatically.
