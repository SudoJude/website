# Portfolio

Astro site deployed to GitHub Pages.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
```

Edit `src/data/site.ts` for your name, bio, links and projects.
Set `site` and `base` in `astro.config.mjs` (see comments there).

## Deploy
Push to `main`, with Settings → Pages → Source set to **GitHub Actions**.
Set the custom domain DNS (see GitHub docs) and enable Enforce HTTPS in Pages settings.
